Tujuan utama saya adalah bisa mengolah *raw data* menjadi sebuah *insight* berharga yang dapat digunakan untuk membuat keputusan secara akurat dan objektif, bukan sekadar menebak-nebak.

## 📈 Harapan Capaian Belajar (Expected Outcomes)
Saya berharap dapat mencapai beberapa target teknis dan analitis berikut:
* **Fundamental Analisis:** Memahami konsep dasar statistik dan matematika yang menjadi tulang punggung pengolahan data.
* **Tech Stack Mastery:** Menguasai bahasa pemrograman (seperti Python) beserta *library* esensialnya (misal: Pandas, NumPy, atau Scikit-learn).
* **Data Storytelling:** Mampu melakukan *Exploratory Data Analysis* (EDA) dan merancang visualisasi data yang informatif agar mudah dipahami oleh siapa pun.
* **Problem Solving:** Mampu merancang dan mengimplementasikan model *Machine Learning* sederhana untuk menyelesaikan studi kasus dunia nyata.
